# Linux Day 2

## Commands Learned

### cat

Purpose:
Displays the contents of a file.

Syntax:
cat filename

Example:
cat notes.txt

Output:
Shows all text stored inside notes.txt

---

### clear

Purpose:
Clears the terminal screen.

Syntax:
clear

Example:
clear

Output:
Terminal becomes clean.

---

### history

Purpose:
Displays previously executed commands.

Syntax:
history

Example:
history

Output:
Shows command history list.

---

### echo

Purpose:
Prints text on the terminal or writes text into a file.

Syntax:
echo "text"

Example:
echo "Hello Linux"

Output:
Hello Linux

---

### man

Purpose:
Displays the manual page of a command.

Syntax:
man command_name

Example:
man ls

Output:
Opens detailed documentation for the ls command.
