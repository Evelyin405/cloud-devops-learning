# Linux Day 1

## Commands Learned

### lsb_release -a
Shows Ubuntu version information.

### pwd
Shows current working directory.

### ls
Lists files and folders.

### mkdir
Creates a folder.

### cd
Changes directory.

### touch
Creates an empty file.

Interpretaion of commands: 
1. lsb_release -a

Purpose:
Shows Ubuntu version information.

Example:

lsb_release -a
2. pwd

Purpose:
Shows your current directory.

Example:

pwd
3. ls

Purpose:
Lists files and folders.

Example:

ls
4. mkdir

Purpose:
Creates a folder.

Example:

mkdir Linux
5. cd

Purpose:
Moves into a folder.

Example:

cd Linux

To come out:

cd ..
6. touch

Purpose:
Creates an empty file.

Example:

touch notes.txt
